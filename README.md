# ヨミアテ（yomiate）

**推理は、情報の買い物だ。** 4桁の数字当て（ヒット&ブロー）に「ヒント購入」と「残り候補数メーター」を足した推理ゲーム。完全ブラウザ内・ゼロ依存。`index.html`を開くだけ。

## ルール

- 隠された数字（重複なし）を当てる。予想にはH（位置も一致）/B（数字のみ一致）が返る
- 桁数はフリーモードで選択: **4桁(5040通り・8手)／5桁(30240通り・10手)／6桁鬼(151200通り・12手)**。デイリーは4桁
- **スコア制**: 最大1000点＝速いほど高得点・ヒント1回−100・手数超過−50/手
- 入力は**テンキー配列**（789/456/123/⌫0判定）・物理キーボード対応（数字/Backspace/Enter）・マスをタップして置き換え可
- 💰 ヒント購入（1回=1手・各1回）: 合計は？／偶数は何個？／最大は？／1桁開示／「Xはある？」
- 📉 **残り候補数メーター**: 全ての情報と矛盾しない候補数を常時表示。「その質問、候補を1/40にした」が見える＝**情報量の体感教材**

## モード

- 📅 **きょうのヨミアテ**: 全員同じ日替わり問題（#通し番号・1日1回・連続記録）。結果は絞り込み履歴つきでコピー→Xへ（`候補: 5040→680→95→3→✅`——ネタバレなしで上手さが伝わる）
- ♾ フリー: 何度でも
